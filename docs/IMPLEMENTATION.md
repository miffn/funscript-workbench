## 扫描目录选择与持久化（2026-09-30）

设置页新增已配置目录的勾选与“保存扫描目录”，SQLite 的 `scan_roots` 设置记录启用目录和修订号。旧库默认全部启用，至少保留一个目录；空选择、非配置路径返回 422，多客户端旧修订提交返回 409。保存本身不触发扫描，轮询不覆盖未保存草稿，失败可重试，版本冲突通过显式放弃选择并加载最新设置处理。

`GET /api/settings` 提供 `roots[].enabled` 与 `scan_roots_revision`；`PUT /api/settings/scan-roots` 接收 `enabled_paths`、`expected_revision` 并返回完整设置。扫描任务在 inputs 保存启用目录和修订号，重启按原快照继续；不同目录范围的任务不合并。扫描和封面生成只读取任务范围，未选目录的关联、素材、异常及缓存保留。跨根同编号作品的封面仅从选中根取源，生成失败保留已有可用缓存。目录打开和独立预览沿用全部已配置根目录的原权限校验。
