# 发帖资料与模板需求

版本：v0.3。日期：2026-09-30。状态：标签维护与一次性资料导入已实施；发帖正文生成和库存链接编辑仍待实施。

## 已确认的目标

工作台自动读取编号库存与关联素材。用户主要负责绑定视频作者、维护每个库存的 ES 帖子链接、Patreon 链接、视频链接及脚本下载链接，并逐个选择发布类型和档位；其余能够可靠提取的资料与帖子内容自动生成。

用户进一步确认采用标签维护：标签及其资料存入数据库，与库存建立绑定。作者名字是作者标签，其支持作者 URL 与该标签一起维护；给库存打上作者标签即可复用支持地址。其他适合分类的信息也通过标签选择和维护，作品自己的链接仍手动填写。

可一次性导入用户提供的本地历史资料，之后仅在工作台维护。

## 数据划分

| 数据 | 来源与维护方式 |
| --- | --- |
| 完整编号、目录、视频、脚本、封面 | 现有库存扫描；子编号独立 |
| 时长、具体轴、单轴/多轴 | 读取选定视频与精确关联的脚本组 |
| 发布标题 | 优先保留已导入的发布标题；新库存从脚本标题或视频文件名获得默认值，可修改 |
| 视频类型 | 优先已有资料；建议作者可配置默认类型，库存可覆盖，不凭视频文件猜测 |
| 作者 | 作者标签维护名称、支持地址等资料；用户给库存打作者标签 |
| 发布类型、档位 | 每个库存由用户选择对应分类标签；不从视频类型、时长或是否有 Patreon 链接推断 |
| ES 帖子、Patreon、视频、脚本下载地址 | 用户逐个库存手动维护，持久化保存 |
| 本地预览、GIF、未来热力图 | 关联已有生成结果；本地文件与 ES 上传地址分别保存 |
| 帖子标题、正文与固定导航 | 模板结合上述资料自动生成 |

发布类型使用现有 `Free Sample` / `Paid`；档位使用现有 `Free` / `Main Tier` / `Extra Tier`。两者应校验合理组合，不允许用扫描或重新生成覆盖用户选择。

脚本链接明确指网盘或其他下载地址，不强制要求 ES 上传附件 Markdown。具体公开展示规则仍待确认。

## 标签维护方式

标签是有类别、可带资料的数据库记录，而非仅保存显示文字。库存绑定标签记录，标签改名不丢失绑定；支持地址保存在作者标签上，不复制到每个库存中反复维护。

| 标签类别 | 示例 | 附带资料或使用规则 |
| --- | --- | --- |
| 作者 | 示例作者 A、示例作者 B | 支持作者 URL；建议可配置默认视频类型。支持地址可标记未填写或明确无地址 |
| 视频类型 | Real、Anime、3DCG、VAM | 供模板显示与筛选；同一库存选择一个分类 |
| 发布类型 | Free Sample、Paid | 用户选择，供模板决定内容分支 |
| 档位 | Free、Main Tier、Extra Tier | 用户选择，与发布类型组合校验 |
| 自定义分类 | 用户定义 | 可用于管理和筛选；是否进入公开帖子须由模板明确配置，不能把所有标签直接发布 |
| 自动信息 | Stroke、Pitch、Multi-axis | 从对应素材提取并显示为标签；扫描负责更新，不与用户选择混用 |

作品的 ES、Patreon、视频和脚本下载地址仍单独保存，不放进共享标签。现有待发布/已发布状态继续独立维护，不因打标签或生成帖子发生变化。

建议交互：库存详情搜索并点选标签，必要时快速创建作者标签；单独的标签管理入口编辑作者名称与支持地址等资料；库存列表按标签筛选。已绑定作者再次使用时无需重新填写其支持地址。视频类型等分类标签限制冲突选择，避免同时打上互斥标签。

建议生成行为：修改作者标签后，相关库存下次生成帖子使用新资料；已保存的正文保留生成时内容，重新生成时才更新。扫描和导入不覆盖用户已经选择的标签与手填链接。

## 初始资料导入

按完整编号导入本地资料中的标题、作者、作者支持地址、视频类型、发布类型、档位和作品链接。同字段冲突保留来源并提示，不覆盖人工维护值。

只关联已经通过目录扫描发现的正式库存。没有对应编号目录的文档行保留为未匹配资料，不凭表格创建库存。原视频和脚本保持只读。

作者资料可从现有 Creator 去重建立候选标签记录；同名作者的支持地址冲突不能自动选一个。缺少作者、支持地址或视频类型时显示待补充状态，不伪造内容。先在作者标签上维护支持地址及明确无地址状态，再供绑定库存复用。已导入的视频类型、发布类型和档位转换为对应分类标签，保留来源。

文档中的状态和计划日期不得覆盖工作台已有发布状态，也不能充当实际发布日期。私有 Notes 和工作台内部备注不进入公开正文。

## 模板方案（尚待确认）

模板可组合以下内容：当前作品信息/预览、折叠热力图、两列导航、折叠轴说明、最近四个已发布作品、品牌页脚。主题标题单独生成，不重复放入正文。

建议免费帖在折叠 Script File 中展示用户维护的脚本下载地址；付费帖沿用 Patreon 入口，脚本下载地址默认仅保存在工作台。此展示规则需用户确认。

网页建议提供保存资料、生成草稿、复制标题、复制正文与导出 TXT。使用 ES 内嵌媒体时，用户手动上传并回填返回的 Markdown；本地预览路径不能转换成 `upload://` 地址。生成帖子不自动标记已发布。

免费帖输入改为用户明确选择的下载地址。其余模板样式规则按本轮后续对齐结果处理。

## 尚待对齐

- 免费和付费帖子中脚本下载链接的具体展示规则。
- 首版模板编辑范围：固定模板加配置，还是多模板及完整 Markdown 编辑。
- 草稿与上传 Markdown 回填流程；热力图字段可先预留。
- 最近作品是否采用可配置置顶。

## 标签阶段已实施

库存新增不加载封面或视频的“标签列表”，逐行打开独立标签编辑窗口；支持标签搜索、分类选择、清空、保存和“仅看未标注”筛选。标签管理页维护共享名称及作者支持地址，地址可标记未知或明确无地址。作者、视频类型、发布类型和档位单选，自定义标签多选。修改共享作者支持地址后，所有绑定库存复用同一记录。

导入严格匹配完整编号；未匹配资料保留待处理，同名作者的不同支持地址保留候选并提示核对。

导入保留库存原有标题、备注和发布状态。扫描和再次导入保留用户已维护的标签，包括主动清空；导入不回写外部资料源。作者默认视频类型、自动轴标签、库存四类链接编辑和模板生成仍属后续范围。实施与验证证据见 `IMPLEMENTATION.md`。
